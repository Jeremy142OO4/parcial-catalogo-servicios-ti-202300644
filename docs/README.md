# Documentación del proyecto

Esta carpeta centraliza la documentación de la solución. Las categorías se mantienen separadas porque la consigna solicita evidencias independientes para contexto, prompts y harness.

La narración principal está en `RESOLUCION.md`. Las carpetas contienen únicamente el material de respaldo necesario para verificar cada afirmación.

## Documentos principales

- [Resolución de la tarea](RESOLUCION.md): problema, arquitectura, reglas, pruebas y estado de cumplimiento.
- La consigna y los archivos de referencia se utilizaron durante el desarrollo, pero no se incluyen en la entrega para evitar duplicar material externo.

## Evidencias por categoría

- [Contexto versionado](contexto/): actualizaciones motivadas por hallazgos o cambios de decisión.
- [Decisiones de diseño](decisiones/): decisiones técnicas y reglas de negocio.
- [Prompts utilizados](prompts/): prompts reales, respuestas y criterios de aceptación.
- [Evidencias de ejecución](evidencias/): pruebas, reportes y ciclos de corrección.
